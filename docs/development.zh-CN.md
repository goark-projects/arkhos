# 开发规范

[English](development.md) | 简体中文

## 分支模型

- `main` 保存仓库初始化、发布文档和稳定基线。
- `dev` 保存下一版 Arkhos 的实现工作。
- 每个有意义的实现切片都应独立测试并提交。

## 本地命令

```bash
go test ./...
go vet ./...
gofmt -w .
git diff --check
```

## 编码规则

- 文件使用 UTF-8 和 LF 换行。
- Go 代码按小包组织，文件职责单一。
- 公共 API 必须显式、Go 原生。
- 代码注释使用标准简体中文。
- Go 行为在声明完成前必须补单元测试。
- 只有对应 Arkarta TCK 通过后，才能对外声明兼容某个 Profile。

## 依赖策略

优先使用 Go 标准库。只有当外部依赖能提供明确的协议或运行时价值，并且不会泄漏到 Arkarta 契约中时，才引入外部依赖。
