# Arkhos 0.0.1

English | [中文](https://github.com/goark-projects/arkhos/blob/v0.0.1/docs/releases/v0.0.1.zh-CN.md)

Release date: September 6, 2026

Arkhos 0.0.1 is the first public Go-native container implementation for the
Arkarta enterprise Web standard. Hertz is the default high-performance engine;
a standard-library `net/http` container remains available.

See the [changelog](https://github.com/goark-projects/arkhos/blob/v0.0.1/CHANGELOG.md#001---2026-09-06)
for the concise version history.

## :star: New Features

- Implement Arkarta Servlet Core and the Session, Multipart, Async/Stream,
  Upgrade, Security, Native I/O, and WebSocket integration profiles.
- Provide Hertz-native and `net/http` containers with shared explicit
  deployment contracts.
- Add a managed Hertz server with readiness, graceful shutdown, immediate
  close, configurable form limits, and request-scoped profile wiring.
- Back all claimed Arkarta profiles with repository TCK runs.

## :lady_beetle: Bug Fixes

- Drain idle keep-alive connections without consuming the shutdown deadline.
- Preserve unlimited request limits and prevent rapid start/stop exit races.

## :package: Installation

```bash
go get goark.dev/arkhos@v0.0.1
```

Go 1.26 or later and Arkarta 0.0.3 are required.

## :white_check_mark: Verification

The candidate passed unit, integration, TCK, vet, and race gates on Windows
Go 1.26 and Debian Linux Go 1.27. CI covers Linux, Windows, and macOS.
