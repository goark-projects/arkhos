# Arkhos 0.0.1

[English](https://github.com/goark-projects/arkhos/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Arkhos 0.0.1 是 Arkarta 企业级 Web 标准的首个公开 Go 原生容器实现。Hertz 是
默认高性能引擎，同时保留标准库 `net/http` 容器。

精简版本历史见[变更日志](https://github.com/goark-projects/arkhos/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-07)。

## :star: 新功能

- 实现 Arkarta Servlet Core，以及 Session、Multipart、Async/Stream、Upgrade、
  Security、Native I/O 和 WebSocket 集成 Profile。
- 提供 Hertz 原生容器和 `net/http` 容器，共用显式部署契约。
- 提供托管 Hertz Server，包括就绪状态、优雅关闭、立即关闭、可配置表单限制和
  请求级 Profile 装配。
- 所有声明支持的 Arkarta Profile 都由仓库内 TCK 结果支撑。

## :lady_beetle: 问题修复

- 排空空闲 keep-alive 连接，避免消耗全部关闭超时。
- 保持无限制请求语义，并防止快速启停时的退出竞态。
- 为标准库 Server 提供安全的请求头、空闲连接和头部大小默认值，且不限制流式响应。

## :package: 安装

```bash
go get goark.dev/arkhos@v0.0.1
```

要求 Go 1.26 或更高版本，并依赖 Arkarta 0.0.3。

## :white_check_mark: 验证

候选版本已在 Windows Go 1.26 和 Debian Linux Go 1.27 上通过单元、集成、TCK、
vet 和 race 门禁。CI 覆盖 Linux、Windows 和 macOS。
